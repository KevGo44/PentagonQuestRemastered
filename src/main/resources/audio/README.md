# Audio sources

Original synthetic mono PCM WAV assets, deterministically generated by `tools/AssetBaker.java`, 22,050 Hz / 16 bit.

Exploration, combat and ambient loops are separate stems. AudioDirector crossfades on enemy engagement and ducks when paused. Seven effects share bounded four-voice pools. Replace WAV files using the same names or adjust AudioDirector to load OGG via jme3-jogg. These are designed placeholders, not recorded Foley or a final orchestral score.

## pentagonradio.wav

The one recorded piece: 48,000 Hz / 16 bit stereo, about 3:04, roughly 34 MB of raw PCM. It is **not** generated by `AssetBaker.java` and must be kept when regenerating the synthetic assets.

It loads as `AudioData.DataType.Stream`, never as a buffer — the decoder reads it progressively instead of holding 34 MB of PCM. Looping a streamed node works because `WAVLoader.ResettableInputStream` implements `SeekableStream`, so the renderer can rewind it with `setTime(0)` at the end of the track. `AssetTest.radioTrackStreamsAndRewindsForLooping` asserts exactly that property.

While enabled it replaces `exploration.wav` as the exploration bed; `combat.wav` still fades in over it. Players switch between the two in the settings page. Converting the track to OGG via `jme3-jogg` would cut roughly 30 MB from the shaded JAR and keeps seekable looping.
